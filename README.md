# mina-font

## A simple program that turns basic text into cute ASCII art

### Requirements:
- Have [Go](go.dev) installed

### Project Setup:


- `git clone git@github.com:swampPr/mina-font.git`
- `cd ./mina-font`
- `go build`
- `go install`



## Commands:

Run `mina-font -f=[FIGLET FONT NAME HERE] -t="TEXT HERE"` to generate ASCII art of the text inputted with the font chosen

Run `mina-font list` to list all available figlet fonts in alphabetical order that can be chosen for generation
